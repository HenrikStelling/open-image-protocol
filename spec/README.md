# OIP specification

- `oip-v0.1-draft.md` — the normative draft (package layout, manifest, renders, context file, verb set, conformance).
- `schemas/oip-manifest.schema.json` — JSON Schema (draft 2020-12) for `oip.json`.
- `examples/` — packages generated by `scripts/make_examples.py` (synthetic DX and NM phantoms plus pydicom sample images). Regenerate with `make examples`.
